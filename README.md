# Charm the Commuter: Forecast a City That Isn't

One line of weather for Drizzlewick, a city that does not exist: light
umbrella rain, 14°C, buses fashionably late — but every puddle reflects a
rainbow, so pack snacks and hope. A forecast to make a bored commuter
smile at the bus stop.

`main.py` (pure stdlib Python) writes the single-line entry to
`/output/entry.txt` and asserts the gate in code: UTF-8, 1–140 characters,
one line, not only whitespace.
